# 网页采集归档系统 · 原型

依据《网页采集归档系统需求文档.md》（DA/T 80-2019）制作的**可交互静态原型**。

- 本次范围：**登录页、工作台，以及系统管理中的“系统参数”“网站管理”“用户管理”“角色权限”“元数据配置”“分类库维护”“归档范围”页**。
- 其余业务模块保留说明性占位页；“字典配置”“四性检测”“存储配置”“备份恢复”“日志管理”仅保留菜单入口，页面留空。
- 无构建依赖、无后端请求，直接打开 HTML 即可评审。

> 本原型仅用于需求与交互评审，不是生产实现。页面中的统计数字、待办数量、通知均为示例数据。

---

## 快速开始

直接双击打开 `index.html`，或在项目目录执行：

```bash
open index.html          # macOS
# 也可以用任意静态服务器，例如：
python3 -m http.server 8080
```

建议使用最新版 Chrome / Edge / Safari。无需安装 Node.js 或任何依赖。

登录后进入 `workbench.html`。工作台依赖会话，若直接打开工作台会被引导回登录页；如需直接查看某个角色视角，可使用原型专用的直链参数：

```text
workbench.html?role=archive-staff#/workbench
workbench.html?role=site-admin#/workbench
workbench.html?role=site-clerk#/collect
```

`?role=` 仅用于原型演示与截图，正式实现不应保留。

## 演示账号

登录页提供三个“点击填入”的演示账号。**密码不校验**，任意非空密码均可登录；未知用户名会被拒绝。

| 角色 | 用户名 | 演示密码 | 数据范围 |
| --- | --- | --- | --- |
| 档案馆工作人员 | `archive_admin` | `Archive@2026` | 全部网站（示例市本级政府网站及部门网站） |
| 网站主办单位系统管理员 | `site_admin` | `Site@2026` | 示例市大数据管理局 |
| 网站主办单位档案员 | `site_clerk` | `Clerk@2026` | 示例市大数据管理局 |

会话保存在 `sessionStorage`，关闭标签页即失效；“记住用户名”只把用户名写入 `localStorage`，不保存密码。

## 已实现内容

### 登录页 `index.html`

- 左侧品牌区：系统定位、DA/T 80-2019 标识、三项能力说明、归档流程示意。
- 右侧登录卡：用户名 / 密码、密码显示切换、记住用户名、忘记密码提示、登录 loading 态。
- 表单校验：必填校验、未知账号提示、字段级错误 + 顶部提示，错误与输入框通过 `aria-describedby` 关联。
- 演示账号一键填入；移动端隐藏品牌区、显示紧凑品牌头。

### 工作台 `workbench.html#/workbench`

- 角色化数据范围：档案馆工作人员看全部网站；主办单位角色只看本单位，并在图表与脚注中明确口径。
- 4 张关键指标卡：采集网站、采集栏目、采集网页、已归档（含环比/近 7 日说明）。
- 采集与归档数量：按网站 / 按栏目切换的分组横向柱状图，含坐标轴、图例、单位、口径说明与数据表。
- 文件类别分布：环形图 + 数量/占比图例，四类合计等于已归档件数。
- 采集与归档趋势：近 12 个月双折线图，含月份轴、单位、部分月份说明。
- 归档概览：本年归档完成度、四性检测通过率、3 条可跳转待办。
- 刷新按钮：模拟 700ms 加载态并提示“静态示例数据不会变化”。
- 图表支持鼠标悬停与键盘聚焦查看数值；视觉上隐藏的数据表供读屏使用。

### 系统参数 `workbench.html#/system/params`

- 左侧纵向分类：外观参数 / 应用参数 / 业务参数；窄屏转为顶部横向页签。当前仅**外观参数**提供参数表（7 项）；应用参数、业务参数只保留分类标签，进入后显示未生成提示。
- 外观参数表：序号、描述、配置项、配置类型、参数值，共 7 项，与需求文档及参考图一致。
- 外观参数工具栏：参数配置、搜索、刷新、参数说明；搜索按描述 / 配置项 / 参数值过滤，说明浮层解释文本、数字、选择、本地资源四类。
- 参数配置：列表内联编辑，文本/数字使用输入框、选择项使用下拉；保存前校验（必填、数字范围、枚举合法性），错误定位到字段；支持取消。
- 批量恢复默认值：勾选行后恢复，表头支持全选 / 半选；页脚实时显示已选数量。
- 保存仅写入当前会话的模块内存，刷新页面恢复示例值；顶部与页脚均提示“仅当前会话生效”。应用参数、业务参数不提供编辑与列表。
- 仅档案馆工作人员可见；其他角色访问 `#/system/params` 会回到工作台并提示无权访问。

### 网站管理 `workbench.html#/system/sites`

- 左栏网站列表：网站名称、域名、全宗号、栏目数与状态；支持按名称、域名、主办单位搜索，选中项高亮。
- 网站基本信息通过弹窗查看与编辑：名称、域名、网站代码、主办单位名称、主办单位全宗号、采集状态；右侧“网站信息”“编辑信息”打开弹窗，保存前校验必填、域名格式、域名重复、网站代码格式与重复、全宗号格式。
- “新增网站”使用弹窗；保存后自动选中新网站并切换到其栏目区，可继续添加栏目。
- 网站列表每一项右下角提供删除按钮，打开二次确认弹窗，展示网站域名、全宗号及将一并删除的栏目数；确认后删除该网站及其栏目，当前网站被删除时自动选择相邻网站，全部删除后显示空列表与“尚未选择网站”栏目空态。
- 右栏栏目管理：频道名称、一级栏目、二级栏目、访问地址、状态；支持弹窗新增与编辑栏目、行内删除二次确认、按频道/栏目/地址搜索。
- 弹窗支持 Escape 关闭、点击遮罩关闭、焦点限制在弹窗内并在关闭后归还触发按钮；打开时锁定页面滚动。
- 页面不提供“重置数据”按钮；全部修改仅写入当前会话内存，刷新页面即恢复示例值。主办单位系统管理员只看到本单位（示例市大数据管理局）的 4 个网站，新增网站的主办单位锁定为本单位。
- 归档范围、状态等业务规则仅作界面与校验演示，不产生真实采集任务。
- 档案馆工作人员可见全部网站；主办单位系统管理员仅可进入本页并管理本单位网站与栏目，其他角色访问 `#/system/sites` 会回到工作台并提示无权访问。

### 用户管理 `workbench.html#/system/users`

- 档案馆工作人员视角示例 6 个用户、3 个角色；主办单位系统管理员只看到本单位（示例市大数据管理局）的 2 个用户，工具栏与页脚展示当前范围内的总数与状态统计。
- 工具栏：按用户名 / 姓名 / 主办单位搜索，按角色、状态筛选，一键清空筛选；空结果提供“清空筛选”动作。
- 表格：用户名、姓名（含“本人”标识）、角色、主办单位、状态、最近登录、操作。
- 新增用户：弹窗填写用户名、姓名、角色、主办单位、初始密码、账号状态；校验用户名格式与唯一性、必填、密码至少 8 位、主办单位；新用户默认启用。主办单位系统管理员新增用户时，主办单位锁定为本单位，角色只能选择本单位的系统管理员或档案员。
- 编辑用户：弹窗修改姓名、主办单位、角色、状态，可选填新密码；当前登录账号的用户名、角色、状态锁定，不能停用或删除自己。
- 重置密码：独立弹窗，新密码与确认密码需一致且至少 8 位；原型不保存明文密码，仅校验长度与一致性。
- 停用 / 启用、删除用户均使用二次确认弹窗；删除当前登录账号的入口禁用。
- 页面不提供“重置数据”按钮；所有修改仅写入当前会话内存，刷新恢复示例值。
- 档案馆工作人员可见全部用户；主办单位系统管理员仅可进入本页并管理本单位用户，其他角色访问 `#/system/users` 会回到工作台并提示无权访问。

### 角色权限 `workbench.html#/system/roles`

- 左侧角色列表：3 个内置角色（档案馆工作人员、主办单位系统管理员、主办单位档案员）；不预置自定义角色，可通过“新增角色”创建。显示角色编码、用户数与状态，支持按名称 / 编码搜索。
- 右侧角色详情：角色名称、编码、数据范围（全部网站 / 本单位网站）、角色状态、角色描述；内置角色的名称、编码、数据范围、状态只读，自定义角色可编辑。
- 菜单权限：业务功能 6 项 + 系统管理 12 项；分组全选、单项勾选与半选态，实时统计“已选 N / 18 项”；至少保留 1 项，否则保存时提示“请至少勾选一个菜单权限”。
- 默认菜单：档案馆工作人员 18/18、网站主办单位系统管理员 3/18、网站主办单位档案员 8/18。
- 保存 / 撤销修改；保存后同步左侧角色名称、状态与菜单数量。
- 新增角色：弹窗填写名称、编码、数据范围与描述，初始仅授予“工作台”；编码需符合 3–32 位小写字母/数字/下划线且唯一。
- 删除角色：仅允许删除 0 个用户的自定义角色；内置角色或仍被用户引用的角色删除入口禁用，二次确认弹窗会说明菜单权限一并移除。
- 角色与用户数据共享；角色下的用户数来自用户管理。权限修改不即时改变当前登录菜单，需切换角色或重新登录生效（原型中切换“原型视角”即可看到）。
- 页面不提供“重置数据”按钮；所有修改仅写入当前会话内存，刷新恢复示例值。
- 仅档案馆工作人员可见；其他角色访问 `#/system/roles` 会回到工作台并提示无权访问。

### 元数据配置 `workbench.html#/system/metadata`

- 收集库 / 归档库两个标签独立配置，各自包含 19 个内置字段：网站名称、网站域名、标题、副标题、栏目、发布时间、来源、关键词、作者、摘要、网址、全宗号、网站代码、年度、保管期限、类别代码、顺序号、采集时间、采集人。
- 表格展示排序、著录项名称（含提示语与内置/自定义标记）、数据类型、总长度、必填、只读、元数据、字典类型、默认值类型与操作；顶部统计字段总数、内置/自定义数量与只读字段数。
- 必填、只读可在表格内直接切换；上下箭头调整字段顺序；支持按著录项名称、提示语或元数据搜索。可检索、列表显示在弹窗内配置。
- 新增著录项弹窗按参考图排列：著录项名称、提示语、数据类型、总长度、是否必填、是否只读、元数据、字典类型、默认值类型，以及按条件出现的默认值和选项配置，最后是可检索与列表显示；名称为空、长度非 1–2000、选择类型无选项、固定默认值未填写时在字段下方显示错误。
- 编辑著录项：内置字段的名称与数据类型锁定，可调整总长度、必填、只读、元数据、字典、默认值与检索/列表设置；自定义字段可完整修改。
- 元数据按著录项名称自动匹配，也可手动选择；默认值类型支持无 / 固定值 / 当前日期 / 当前用户 / 当前年度，固定值时显示默认值输入。
- 列表每行提供删除；内置与自定义著录项均可删除，删除使用二次确认弹窗。删除仅影响当前会话，刷新页面恢复 19 个内置字段；另一个库不受影响。
- 页面右上角“规则设置”打开规则配置弹窗：左侧列出档号规则、表单规则、列表规则、排序规则、名称规则、分类规则、报表规则、存储规则、流水号规则、关键字规则、归档章配置、字段分组规则、批量筛选规则、检索字段规则 14 项，点击切换右侧配置区。
- 当前仅实现“档号规则”：提供两种二选一的组合方式，分别为“全宗号-WY-网站代码-年度-保管期限代码-类别代码-顺序号”和“全宗号-WY-网站代码-年度-类别代码-保管期限代码-顺序号”；保存仅写入当前会话。其他 13 项规则保留入口与占位说明，暂不生成配置表单。
- 所有修改仅写入当前会话内存，刷新恢复示例值；字段顺序作为采集列表、档案列表与详情页的展示顺序说明。
- 仅档案馆工作人员可见；其他角色访问 `#/system/metadata` 会回到工作台并提示无权访问。

### 分类库维护 `workbench.html#/system/category`

- 内置 6 个分类：网站及栏目首页（LMSY）、信息发布类（XXFB）、解读回应类（JDHY）、办事服务类（BSFW）、互动交流类（HDJL）、其他类（QT）；备注为示例说明。
- 列表展示序号、分类名称（含“内置”标记）、类别代码、备注与操作；支持按名称、代码或备注搜索，顶部显示记录数。
- 新增/编辑弹窗字段为分类名称、类别代码、备注；名称与代码必填，代码统一转大写、限 2–20 位大写字母或数字且全库唯一，备注选填、最多 200 字。
- 内置与自定义分类均可编辑、删除；删除使用二次确认弹窗，并提示使用该分类的网页档案将失去分类映射。
- 所有修改仅写当前会话内存，刷新恢复 6 个内置分类；页面不提供重置按钮。
- 仅档案馆工作人员可见；其他角色访问 `#/system/category` 会回到工作台并提示无权访问。

### 归档范围 `workbench.html#/system/scope`

- 表格按《归档范围与保管期限表》录入 26 行：5 个大类、21 个明细，列为序号、归档范围、保管期限；大类行为浅底加粗，保管期限显示“—”。
- 序号与归档范围均为可直接编辑的文本单元格（归档范围多行自适应），保管期限为下拉（永久 / 30 年 / 10 年）；修改后顶部“保存修改”才可用，保存写入当前会话。
- 页面右上角提供“导入三合一表”“导出三合一表”：导入支持 CSV / JSON（Excel 文件需先另存为 CSV），导出生成带表头的 UTF-8 CSV，可用 Excel 打开。
- 导入会校验表头与“归档范围”列；序号为整数的空保管期限行识别为大类，其余为明细；导入结果直接写入当前会话。
- 空归档范围保存时阻止并定位到该单元格；页面不提供重置按钮，刷新恢复 26 行示例表。
- 仅档案馆工作人员可见；其他角色访问 `#/system/scope` 会回到工作台并提示无权访问。

### 应用壳与占位页

- 侧栏按角色生成菜单；系统管理为可折叠子菜单。档案馆工作人员可见全部 12 个系统页，主办单位系统管理员只显示“网站管理”“用户管理”。
- 顶栏：面包屑、原型视角切换、通知下拉、用户下拉、退出登录。
- 系统参数、网站管理、用户管理、角色权限、元数据配置、分类库维护、归档范围页已实现；5 个业务模块渲染统一占位页：模块说明、已规划能力清单、返回工作台入口、原型提示。
- “字典配置”“四性检测”“存储配置”“备份恢复”“日志管理”保留菜单与路由，内容区留空，用于表示本阶段不生成页面。
- 非法地址或越权地址会回到工作台并给出 warning toast。
- 移动端：侧栏抽屉 + 遮罩、Escape 关闭、跳转后自动收起；提供 skip link。

├── assets

## 设计基线

- 视觉遵循 Ant Design 规范，颜色、字号、间距、圆角、阴影全部收敛在 `tokens.css`，页面中不写死十六进制颜色。
- 正文 14/22，辅助 12/20，区块标题 16/24，大数字 30/600；控件高度 32（登录输入与主按钮 40）；卡片圆角 8、控件圆角 6、标签 4；间距 4px 栅格。
- 菜单页不展示页面级 h1 标题；内容区页边距 8px、不设最大宽度，页面级操作保留在右上角。
- 组件形态对齐 NG-ZORRO：按钮、输入、下拉、分段控制器、进度条、空态、通知。
- 图标为内联 SVG sprite（lucide 风格 stroke），不依赖图标字体或第三方库。
- 可访问性：`:focus-visible` 统一焦点环、skip link、语义化标题与地标、下拉 `aria-expanded`、图表 `aria-label` + 隐藏数据表、`prefers-reduced-motion` 降级。
- 响应式断点：1200（隐藏视角切换）、992（侧栏转抽屉）、768（页头纵排、隐藏用户名）、576（指标卡单列、分段控件换行）。

## 与正式实现的迁移路径

当前工作区只有需求文档，没有 Angular 工程或 `package.json`，因此按静态原型方式交付。正式实现建议：

1. 新建 Angular 工程并接入 NG-ZORRO 与私有 `ng-shared` 组件库。
2. 将 `index.html` 迁为独立登录路由（无应用壳），`workbench.html` 迁为带布局壳的 `WorkbenchComponent`；其余路由按现有 hash 结构注册。
3. 图表替换为团队图表封装（保持现有颜色 token、标题/单位/图例/空态规则）。
4. `data.js` 拆为 `DashboardService`、`MenuService`、`SessionService`；角色菜单改为权限服务 + 路由守卫。
5. 登录接入真实认证、失败锁定、验证码与审计日志；会话改用服务端会话或短期令牌。
6. 系统参数页迁移为 `ParamService` + NG-ZORRO 表单项/表格；网站管理迁移为 `SiteService` + `ColumnService`，列表改用 `app-table`、新增/编辑改用抽屉或弹窗、删除改用 `Modal.confirm`，保存改为后端接口并记录审计日志；用户管理、角色权限迁移为 `UserService` + `RoleService`，用户、角色与菜单权限关系落库，删除角色前校验引用并写审计日志；其余占位页按需求文档逐模块实现，`app-table`、`StepHandler`、弹窗/抽屉统一使用 `ng-shared` 形态。

## 已知限制

- **主色按钮对比度**：`#1677FF` 配白字对比度约 **4.1:1**，低于 WCAG AA 对 14px 正文的 4.5:1 要求；`#0958D9` 约为 6.16:1。原型沿用 Ant Design 主色，正式实现建议主按钮使用更深的主色，或提高字号/字重。
- 图表在窄屏（<768）保持最小可读宽度并横向滚动，已提示“左右滑动查看完整图表”，未做移动端专用图表。
- 工作台只抽取 8 个网站 / 8 个栏目做可视化，不代表全量数据；真实项目需分页、聚合与导出。
- 工作台的主办单位视角示例与网站管理示例不是同一套聚合数据：工作台展示本单位 4 个网站，网站管理展示其中 4 个示例网站及其 7 个示例栏目，仅用于演示界面与范围过滤，口径不联动。
- 网站删除仅移除当前会话数据，不删除真实归档文件；确认弹窗会提示不可撤销，刷新页面恢复示例。栏目删除仍为行内二次确认；窄屏栏目表横向滚动，767px 以下显示滑动提示。
- 用户管理：当前登录账号不可修改用户名/角色/状态、不可停用或删除自己；账号密码仅做长度与一致性校验，不保存明文。
- 角色权限：内置角色不可改名/编码/数据范围/停用/删除；自定义角色仅在 0 用户时可删除；角色权限修改不即时刷新当前会话菜单。
- 分类库维护：内置分类可编辑、删除，刷新页面恢复 6 个内置项；正式实现应增加分类引用校验、代码不可变策略与审计日志。
- 元数据配置：默认内置 19 项，内置与自定义字段均可删除，删除后刷新页面恢复示例；字段顺序与开关仅作前端演示，未与采集模板、列表列配置或档案目录结构联动；新增字段不参与真实采集校验。规则设置仅供原型评审，除档号规则外其余 13 项规则未生成配置页面。
- 字典配置、四性检测、存储配置、备份恢复、日志管理按本轮要求不生成页面，菜单点击后内容区为空。
- 归档范围导入仅支持 CSV / JSON，暂不解析 Excel；导出为 CSV，不保留合并单元格、字体等版式。
- 未实现暗色模式、国际化、打印样式。
- 主办单位数据范围由前端按 `org` 过滤演示，正式实现必须由服务端按单位 ID 强制过滤并做接口鉴权。
- 原型不持久化任何修改；系统参数、网站管理、用户管理、角色权限、元数据配置、分类库维护、归档范围的保存只写入当前会话内存，刷新即恢复示例值；页面不提供“重置数据”按钮；应用参数、业务参数仅保留分类标签，切换角色、标记已读、退出登录也只在浏览器内模拟。
- 需求文档中“角色权限”说明在“网站主办单位系统管理员”处截断，当前按 3 个内置角色、6 项业务菜单 + 12 项系统菜单实现，自定义角色通过新增创建，权限矩阵为合理推断，需业务确认。
